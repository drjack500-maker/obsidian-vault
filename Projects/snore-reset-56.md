# SNORE RESET 56

いびきのセルフケアを56日間で習慣にするプログラム（医療法人とは別事業）。
導線: 広告 → 無料56秒スターター動画 → メール登録 → 56日プログラムの説明 → 7日体験 → 有料アプリ購入。
コンセプトは「56秒で治す」ではなく「56秒で始めて、56日で習慣化する」。

### 構成とナレーション

| 時間 | 場面 | ナレーション |
| --- | --- | --- |
| 0:00 | オープニング | 今夜、まず56秒。いっしょに始めましょう。 |
| 0:04.6 | 準備（姿勢・鼻呼吸） | 背すじを伸ばして、鼻から吸って…／ゆっくり、吐いて… |
| 0:09.9 | STEP 1 舌スライド（約2秒×5回） | 舌先を、前歯のすぐ裏へ。／上あごを、なぞって奥へ。／2回目〜ラスト |
| 0:23.7 | STEP 2 舌の吸いつけ（5秒キープ×2回） | 舌全体を、上あごにピタッ。／あと2秒。／ゆるめて。（2回） |
| 0:38.6 | STEP 3「アー」発声（×3回） | 口を大きく開けて、アー。／のどの奥を、上げるように。／もう一回、アー。／ラスト、アー。 |
| 0:50.5 | エンディング | おつかれさまでした。／明日の夜も、同じ56秒を。 |

### 表現上の注意

- 3つの動きは、2015年のランダム化試験（PubMed 25950418）の口腔咽頭エクササイズから選んだスターター用の短縮版。「56秒で改善する」とは言わない
- エンディングに「効果を保証するものではありません」「呼吸が止まる・強い日中の眠気などがある場合は医療機関へ」を表示
- 監修者がいれば公開前に確認してもらう。声の商用利用条件は Higgsfield の規約・プランで確認

### 直すとき

- 文言・色・図は `scene.html`、タイミングとナレーション原稿は `timeline.js`、音は `audio.py`。`node render.js` で書き出し直す
- 声は Higgsfield（ElevenLabs v4・プリセット「Maya」）で1行ずつ作り `narration/` に置く。読み間違えやすい語はかなで書く（[[tts-japanese-narration]]）
