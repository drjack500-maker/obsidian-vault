# 日本語ナレーションの音声合成：読み間違いと確認方法

## 読み間違えた語と対処（ElevenLabs v4）

| 書いた文 | 音声認識で聞こえた読み | 対処 |
| --- | --- | --- |
| 背すじを伸ばして | ベースじ | 「せすじ」とかなで書く |
| 3回目 | 了解ね | 「さんかいめ」 |
| 口を（文の頭） | こっち | 「くちを」 |
| 舌先を（文の頭） | したせ | 「したさき」 |
| 上あごを（文の頭） | 不明瞭 | 「うわあご」 |

- 文の頭の漢字が崩れやすい。字幕用の文（漢字）と、読ませる文（かな混じり）を分けて持つ
- 同じ文でも生成ごとに読みが変わる。怪しい行は2通り作って良い方を選ぶ

## 確認方法（自分で聞けないとき）

- faster-whisper で書き起こして確認する。large-v3-turbo が一番正確
- faster-whisper 1.2.1 は PyAV の版の違いで音声ファイルを直接開けない（`open() got an unexpected keyword argument 'metadata_errors'`）→ ffmpeg で 16kHz モノラルの float32 に変換し、配列で渡す
- 無音や音楽だけの区間に出る「ご視聴ありがとうございました」は Whisper の幻聴。実際の音声ではない
- 1行ずつ作った声は、前後の無音を切ってから「声が出始める時刻」で並べると、画面の動きと合わせやすい
